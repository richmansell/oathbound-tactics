# Oathbound Tactics — Audio Credits

Every audio file shipped in `public/assets/audio/` is listed below with its title, author, licence and source.
This file is a legal requirement for the CC-BY assets: keep it in sync with `src/audio/manifest.ts` (the
`tests/audio-manifest.test.ts` test fails if a shipped file has no entry here) and surface these credits in the
game's credits screen.

Licences: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) · [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/) · [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/). No NC/ND/SA material is used.

**Modifications** (CC-BY "indicate if changes were made"): unless noted, files were trimmed, loudness-normalised and
transcoded (AAC/.m4a); SFX marked *layered* are new compositions mixing the listed sources, sometimes with pitch
shifting, filtering, saturation and synthetic layers. Seamless-loop music MP3s are the composer's original encodes,
losslessly truncated at an MP3 frame boundary shortly after the loop end (no re-encode).
