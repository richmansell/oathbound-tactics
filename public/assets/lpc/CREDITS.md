# Sprite credits

Character sprites in this directory come from the **Liberated Pixel Cup (LPC)** community, collected by the
[Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator) (commit `86160e7507d6841259cff624a51a63c1d4847ee3`).
Files were re-encoded losslessly (indexed PNG) but are otherwise unmodified; some items are recoloured at runtime
using the LPC palette definitions. Generated by `tools/lpc-import.mjs` — do not edit by hand.

Most assets are multi-licensed; you may use them under any one of the listed licences. Attribution is required for
all CC-BY / CC-BY-SA / OGA-BY / GPL assets. Where only share-alike licences (CC-BY-SA, GPL) are offered, the
artwork itself (and derivatives of it) must stay under that licence. See `CREDITS.csv` for a per-file listing.
